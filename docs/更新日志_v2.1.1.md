# CaseOrCake 更新日志（v2.1.1 · 2026-08-13）

修复与品牌更新。与旧版同一签名，**直接覆盖安装即可，数据保留**。
本版本起应用正式更名为 **CaseOrCake**。

## Bug 修复

1. **记账小数金额被统计成整数**：统计卡片（收入/支出/结余）、今日支出、预算已用、饼图总支出、清单预计花费之前用 toFixed(0) 强制取整，输入 12.5 会显示成 13。现统一改为金额格式化：整数不带小数点、含小数保留两位。
2. 逐行账目金额统一两位小数口径（12.5 → 12.50），与主流记账软件一致。
3. 消费结构饼图中心金额偶现浮点尾数（如 123.30000001），已按分舍入清理。

## 品牌更新

4. **应用更名**：「生活工作台」→「CaseOrCake」。手机桌面图标名、页内顶栏标题全部更换。
5. **导出路径随品牌更新**：备份文件名改为 CaseOrCake_备份_日期.json；导出目录改为 下载/CaseOrCake。旧备份导入不受影响。
6. **全新应用图标**：镜音双子风格（双子偶像 + 黄橙渐变光芒），适配 mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 全部 5 档分辨率。
7. 构建产物更名：releases/CaseOrCake_v2.1.1.apk。
