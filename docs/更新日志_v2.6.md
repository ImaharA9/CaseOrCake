# CaseOrCake 更新日志（v2.6.0 · 2026-08-22）

真身版本。与旧版同一签名，**直接覆盖安装即可，数据保留**。

## 这一版为什么这么做

上一版小连虽然会成长，但那个形象是用代码一笔笔画出来的小人——精致不起来，也和你的图标（Q 版镜音连）完全两个次元。这次我把"人"彻底换了：让小林真正变成**镜音连**。

## 新形象：五张精致立绘

我和你先对齐了方向（Q 版镜音连 · 小厨师、3D 渲染跟图标一致、继续叫小林、每阶段一张立绘），然后生成了候选图由你拍板，选定后才动手。现在五个成长阶段各有专属立绘：

1. **小林 · 举叉挥手**（Lv1-2）——初始形态，一手举叉子一手跟你打招呼
2. **见习厨师**（Lv3-4）——围上橙色围巾
3. **厨师**（Lv5-6）——端着草莓蛋糕，自信满满
4. **大厨**（Lv7-8）——戴上金色小皇冠
5. **传说大厨**（Lv9-10）——金冠加身、星光环绕的终极形态

全部是和启动图标同款的 3D 渲染 Q 版风格，放进 APP 打包内置，离线也能看。升到新阶段的瞬间会撒花并提示"小林进化啦"。
