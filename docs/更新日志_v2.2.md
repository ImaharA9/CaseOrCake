# CaseOrCake 更新日志（v2.2.0 · 2026-08-15）

界面人性化大改版。与旧版同一签名，**直接覆盖安装即可，数据保留**。

## 视觉与体验重做

1. **今日页渐变英雄卡**：打开 APP 第一眼是一张随皮肤变色的渐变卡片——问候语（按时段配 ☀️🌤️🌇🌙）、日期、随生活指数变化的鼓励文案（分数越高夸得越狠），右侧白色生活指数环。
2. **七大板块都有了性格**：每个板块标题下加了一句情感化副标题，比如习惯「每天一小步，坚持看得见」、跑步「每一步都算数」、清单「想买的先记着，买到的划掉」。标题前还有渐变小竖条标记。
3. **习惯今日进度条**：计数/数值型习惯在打卡区下方显示彩色进度条，一眼看到今天离目标还差多少，达成时显示「已达成 🎉」。
4. **空状态不再冷冰冰**：所有空列表改成「表情 + 一句走心文案 + 行动按钮」，比如空收藏夹是 🎬「看过的好书好片好音乐，都值得留个位置」，并且可以直接点按钮新建。
5. **记账页顶部快捷「记一笔」**：主流记账 APP 的直达记账体验。
6. **细节打磨**：统计卡图标换成彩色气泡底（深色皮肤自动适配）、主按钮加主题投影、习惯卡有按压反馈。

## 图标更换

7. 启动图标更换为自定义 Q 版角色图（已做锐化处理），覆盖 mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi 全部 5 档分辨率。

- 本次为次版本号更新（界面体验大改版），无数据结构变化，覆盖安装后所有记录、习惯、皮肤设置原样保留。
