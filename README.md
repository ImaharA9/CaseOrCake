# CaseOrCake

一个**纯离线、零广告、零账号、零追踪**的安卓个人生活管理 APP。
单文件 HTML + 原生 WebView 壳，APK 仅约 60KB，数据完全保存在本机。
内置 6 款二次元风主题皮肤（含深色模式），顶栏调色盘一键切换。

## 功能模块

| 模块 | 内容 |
|---|---|
| 今日 | 聚合视图、生活指数、待办提醒 |
| 记账 | 收支记录、编辑修改、月度预算、收支对比、消费结构、CSV 导出 |
| 习惯 | 勾选/计数/数值三种打卡、连续天数、30 天热力图、打卡振动鼓励 |
| 健身 | 体重/体脂/BMI、目标进度、热量缺口、周训练计划 |
| 跑步 | 跑步记录、PB 个人纪录、8 周跑量、跑鞋里程寿命 |
| 日程 | 逾期/今天/本周/更远分组视图、点击编辑 |
| 清单 | 待买清单、优先级、预估花费、已购一键转记账 |
| 收藏 | 书影音档案、星级评分、封面墙 |
| 皮肤 | 6 款主题皮肤、深色模式、状态栏/Logo 联动 |

## 下载安装
