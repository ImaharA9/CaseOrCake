# CaseOrCake 更新日志（v2.4.0 · 2026-08-21）

伴侣版本，大更新。与旧版同一签名，**直接覆盖安装即可，数据保留**。

## 这一版为什么这么做

之前的版本一直在调颜色、圆角、动画，但一个生活软件让人想打开的真正理由，从来不是配色——而是"有东西在等我"。Duolingo 有绿猫头鹰，蚂蚁森林有那棵树。所以这版不再打磨外表，而是给软件注入灵魂。

## 新功能

1. **伴侣「小连」**：今日页住进了一个戴厨师帽的小家伙（呼应 CaseOrCake 的名字，也呼应你的图标）。它不是摆设——每次打开都会根据你当下的真实状态说话：
   - 有逾期日程：提醒你先把它们清掉
   - 还有习惯没打卡：告诉你还剩几个，"点一下就算完成"
   - 预算用得多了：让你精打细算
   - 某个习惯连续坚持 5 天以上：点名夸你
   - 今天全部搞定：奖励你一块蛋糕 🍰
   - 什么都不点的时候：戳戳它，它会随机跟你闲聊（还会轻轻震一下）
2. **今日页重构**：打开 APP 第一眼从"数据仪表盘"变成"小连在跟你打招呼"，生活指数环和日期还在，只是换了一种更温暖的方式呈现。
3. **全屏撒花庆祝**：当你把今天的习惯全部打完卡、或者把今日日程全部搞定的那一瞬间，彩纸从屏幕顶部飘落 + 振动 + 专属提示。这是坚持最需要的"被看见"的时刻。计数型习惯达到今日目标也会撒花。
4. **小细节**：小连的身体颜色会跟着你换的皮肤一起变；系统开了"减少动态效果"的话，彩纸会自动跳过。

## 说明
