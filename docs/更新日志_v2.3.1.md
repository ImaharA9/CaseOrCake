# CaseOrCake 更新日志（v2.3.1 · 2026-08-15）

修复与深度柔和化补丁。与旧版同一签名，**直接覆盖安装即可，数据保留**。

## Bug 修复

1. **滑动切换不再闪烁**：上一版的滑动动画播完后，底层还有一条淡入动画会被重新触发，等于每滑一次闪两下。这版把动画机制整个重构——动画只由临时类驱动，播完即干净移除，页面回到完全静止状态，不会再有二次闪烁。
2. 顺手把滑动本身调得更轻：位移从 48px 减到 26px、起始透明度从 0.35 提到 0.55、时长缩到 0.28 秒——只是"轻轻挪过来"，不再是"飞进来"。
3. 点按顶部 Tab 切换也改成了同样的轻淡入，不再有动画打架的问题。

## 第二轮柔和化（更暖、更低刺激）

4. **底色更暖**：从纸白换成奶油色 #F7F4EF，页面顶部再加一层柔和的垂直渐变，打破纯色平面的"数字感"（所有皮肤自动适配）。
5. **文字去纯黑**：正文从纯黑换成柔暖炭色，次级文字全部暖灰化——大面积纯黑文字是界面"硬"的主要来源之一。
6. **主色降饱和**：按钮、激活 Tab、进度条用的主色从饱和靛蓝换成低饱和的雾蓝紫，所有交互元素一起变柔。
7. **阴影变暖**：投影从中性灰改暖褐调；左上角 Logo 加入 8 秒一周期的超缓呼吸。

## 说明

- 修订号版本（修 bug + 体验微调），无数据结构变化，覆盖安装数据保留。
