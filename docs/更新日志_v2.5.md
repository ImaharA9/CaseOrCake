# CaseOrCake 更新日志（v2.5.0 · 2026-08-21）

成长版本。与旧版同一签名，**直接覆盖安装即可，数据保留**。

## 这一版为什么这么做

上一版给软件塞了一颗心——小连住进了今日页。但一个只会说话的伙伴，时间长了还是会变成背景。真正让人"明天还想打开"的，是**看着它因为你而变好**。Duolingo 的猫头鹰会催你，电子宠物会饿，而我要做的是：让小林因为你认真过日子，一点点长大。

## 新功能：小林成长系统

1. **元气**：你的每次习惯打卡、完成的日程、健身和跑步记录、读完看完的作品，都会变成小林的"元气"。元气是靠你真实攒下的数据算出来的——所以**老用户一打开，小林就已经不小了**，这是对过去坚持的迟到认可。

2. **十级成长曲线 + 称号**：小小连 → 见习厨师 → 厨师 → 大厨 → 传说大厨。伴侣卡上现在有一枚等级徽章和一条元气进度条，明明白白告诉你"还差多少元气升下一级"。

3. **样子会跟着变**：升到 Lv3，小林围上橙色围巾；升到 Lv5，戴上小皇冠、身边绕起金色星光。这不是换皮肤，是它真的在"长大"。

4. **升级的瞬间值得庆祝**：每当小林升级，全屏撒花 + 振动 + 告诉你它的新称号。你坚持的意义，在这一刻被看见了。

5. **小林会催你升级**：快到升级门槛时，它会主动开口——"再攒 12 点元气我就升级啦，帮我加把劲"。给"再完成一件事"一个具体的理由。

## 说明

- 次版本号更新（新模块：成长系统）。元气从现有数据推导，**没有新增任何会丢的数据结构**，覆盖安装安全。
- 等级会随 JSON 备份一起迁移，清空数据时一并重置。
